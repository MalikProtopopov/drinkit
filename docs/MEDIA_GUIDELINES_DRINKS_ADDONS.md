# JOOZ — требования к фото/видео для карточек напитков и добавок

> Технические требования к съёмке/рендеру медиа. **Только формат** (как снимать, кадрировать,
> в каком соотношении/разрешении). Само содержание (что за напиток, состав) описывается отдельно
> и здесь не затрагивается. Документ можно отдать фотографу/видеографу или нейросети.

---

## 0. Главное за 30 секунд

- **Напитки:** вертикальное видео/фото **9:16**, напиток **строго по центру**, с запасом по краям.
  Одно и то же медиа показывается и на весь экран, и маленькой почти-квадратной карточкой, и
  крошечной плиткой 80×80 — поэтому объект должен «выживать» при кадрировании в эти формы.
- **Добавки:** **квадрат 1:1, PNG/WebP с прозрачным фоном**, объект по центру с отступами.
- **Никакого текста/логотипов/цен/водяных знаков** прямо в кадре — приложение само рисует текст
  поверх медиа.
- Форматы: фото `jpg/png/webp/avif`, видео `mp4/webm/mov`. **Максимум 60 МБ на файл.**

---

## 1. Где и как используется медиа напитка (факты из вёрстки)

Везде режим **`object-cover`** — медиа **обрезается по центру**, чтобы заполнить контейнер целиком
(пустых полей не остаётся, лишнее по краям отсекается).

| Место | Размер контейнера | Форма (≈) | Что обрезается |
|---|---|---|---|
| Главная — большой блок (hero) | 62% высоты экрана × вся ширина | вертикаль ~3:4…9:16 | по бокам |
| Страница напитка — фон на весь экран | весь экран телефона | очень вытянутая вертикаль ~9:19 | по бокам |
| Плитка в сетке (карточка) | ширина ~172 px × **158 px** | почти квадрат ~1.1:1 | сверху/снизу |
| Миниатюра в корзине | **80 × 80 px** | квадрат 1:1 | сверху/снизу |

Поверх медиа приложение накладывает свои элементы (их **нельзя** дублировать в кадре):
- сверху: логотип JOOZ (слева), кнопки корзины/профиля (справа) + затемнение ~верхние 15%;
- снизу: название напитка и цена (на главной) / панель выбора добавок и кнопка «в корзину»
  (на странице напитка) + затемнение нижней части.

**Вывод:** один вертикальный мастер-файл обрезается и в высокую вертикаль, и в квадрат. Чтобы
напиток был целым во всех формах — он должен помещаться в **центральную квадратную «безопасную зону»**.

## 2. Безопасная зона (драгоценное правило)

Кадр вертикальный **9:16**. Делим по высоте на три части:

```
┌───────────────────────────┐  ← верх 9:16
│   ВЕРХ ~18%: запас         │  поверх ляжет логотип/иконки + затемнение
│   (фон, без важного)       │
├───────────────────────────┤  ─┐
│                            │   │
│      ⌀ НАПИТОК ЦЕЛИКОМ     │   │ ЦЕНТР ~ 60% высоты = БЕЗОПАСНАЯ ЗОНА
│      по центру кадра,      │   │ (центральный квадрат 1:1)
│      бокал не касается     │   │ — виден во ВСЕХ кадрировках
│      боковых границ        │   │
│                            │  ─┘
├───────────────────────────┤
│   НИЗ ~22%: запас          │  поверх ляжет название/цена/панель добавок
│   (фон, без важного)       │
└───────────────────────────┘  ← низ 9:16
```

Правила:
- **Главный объект (бокал/стакан) — точно по центру кадра** и целиком внутри центрального
  **квадрата 1:1** (по высоте это средние ~60%).
- По бокам объекта оставить **≥10–12% ширины** воздуха (тонкая вертикаль на странице напитка
  срезает бока — узкий кадр потеряет края бокала).
- Сверху и снизу — «дышащий» фон, без важных деталей (там лягут текст/кнопки/затемнение).
- **Одинаковый масштаб и ракурс у всех напитков** — чтобы сетка карточек смотрелась ровно
  (бокал занимает примерно одну и ту же долю кадра во всех роликах).

## 3. Напитки — фото

| Параметр | Значение |
|---|---|
| Ориентация | **вертикальная (portrait)** |
| Соотношение | **9:16** (допустимо 4:5, если 9:16 невозможно — объект всё равно по центру) |
| Разрешение | **минимум 1080×1920**, желательно 1440×2560+ |
| Формат | `webp` (лучше всего) или `jpg`; `png`/`avif` тоже принимаются |
| Фон | чистый, ровный, **единый стиль для всех напитков**; занимает весь кадр (он будет виден от края до края) |
| Объект | строго по центру, в безопасной зоне (см. §2) |
| Запрещено | текст, логотипы, цены, водяные знаки, рамки, коллажи |
| Вес файла | до 60 МБ (по факту фото — единицы МБ) |

## 4. Напитки — видео (приоритетно — карточки оживают)

Видео в карточках/hero проигрывается **автоматически, в цикле, без звука, на телефоне**.

| Параметр | Значение |
|---|---|
| Ориентация / соотношение | **вертикаль 9:16** (как фото) |
| Разрешение | **1080×1920** (Full HD вертикаль) |
| Длительность | **4–8 сек**, **бесшовный цикл** (конец плавно переходит в начало) |
| Кодек/контейнер | **MP4 (H.264)** обязательно; webm — опционально |
| Звук | **не нужен** (видео всегда muted) — дорожку можно не прикладывать |
| Частота кадров | 24–30 fps |
| Битрейт | умеренный (мобайл): ~6–10 Mbps; держать вес малым |
| Движение | лёгкое (наливание, лёд, конденсат); камера статична, объект по центру |
| Вес файла | **строго ≤ 60 МБ**, лучше 5–15 МБ ради быстрой загрузки на телефоне |
| Запрещено | текст/логотипы/водяные знаки, резкие склейки, рывок в точке зацикливания |

> Можно прислать **и видео, и фото-постер** к нему (фото показывается, пока грузится видео, и как
> запасной вариант) — желательно один и тот же кадр.

## 5. Добавки (ingredients / boosters) — отдельный формат

Картинка добавки показывается в режиме **`object-contain`** (НЕ обрезается — вписывается целиком),
маленьким значком, **на цветном фоне приложения**. Значит фон самой картинки должен быть прозрачным.

| Параметр | Значение |
|---|---|
| Тип | **фото/иконка объекта на прозрачном фоне** (имбирь, мята, протеин и т.п.) |
| Соотношение | **квадрат 1:1** |
| Фон | **прозрачный** (alpha) — обязательно |
| Формат | **PNG** или **WebP с прозрачностью** (НЕ jpg — он без прозрачности) |
| Разрешение | **512×512** (минимум), 1024×1024 — идеально |
| Композиция | объект по центру, **отступ ~10%** со всех сторон, не упирается в края |
| Свет/тень | мягкая, лёгкая собственная тень допустима (приложение добавит свою) |
| Вес | до ~1–2 МБ |
| Запрещено | непрозрачный фон, текст, рамки, несколько объектов вперемешку |

---

## 6. Общие правила (для всех файлов)

- **Без вшитого текста/логотипов/цен/водяных знаков** — всё это рисует приложение поверх.
- **Единый стиль** набора: одинаковый свет, баланс белого, ракурс, масштаб объекта, фон —
  чтобы сетка и hero выглядели как одна коллекция.
- Допустимые расширения (проверяются на бэке):
  фото — `.jpg .jpeg .png .webp .avif` (и `.gif`); видео — `.mp4 .webm .mov .m4v`.
- **Лимит размера файла — 60 МБ** (жёсткий, больше не загрузится).
- Цветовое пространство — **sRGB**.
- Именование файлов — латиницей, по смыслу: `mango-smoothie.mp4`, `mango-smoothie.jpg`,
  `addon-ginger.png` (название самого напитка/добавки — в отдельном описании, не в файле).

## 7. Готовое ТЗ для нейросети (копировать как есть)

> Технические ограничения генерации/съёмки. Без описания самого продукта — продукт задаётся отдельно.

**Напиток (видео):**
```
Vertical 9:16 video, 1080x1920, MP4 (H.264), 24–30 fps, 4–8 s, seamless loop, no audio.
Single drink centered in frame, fully inside the central 1:1 safe square (middle ~60% of height),
with ≥12% empty margin on left/right and clear background in the top ~18% and bottom ~22%.
Static camera, subtle motion only (pour / ice / condensation). Clean, consistent background
filling the whole frame, edge to edge. No text, no logos, no watermark, no price, no borders.
Same scale and angle across all drinks. File ≤ 60 MB (target 5–15 MB).
```

**Напиток (фото):**
```
Vertical 9:16 still, ≥1080x1920, WebP or JPG, sRGB.
Drink centered inside the central 1:1 safe square; ≥12% side margins; calm background in top/bottom.
Clean background filling the frame edge to edge. No text/logos/watermark/borders. Consistent
lighting, white balance, scale and angle across the set.
```

**Добавка (иконка):**
```
Square 1:1 image of a single ingredient on a FULLY TRANSPARENT background, PNG or WebP with alpha,
1024x1024, sRGB. Object centered with ~10% padding, not touching edges. Soft natural shadow ok.
No text, no frame, no opaque background, one object only.
```
